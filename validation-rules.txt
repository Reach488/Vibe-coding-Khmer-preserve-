Where each rule is enforced:
  DB   = Postgres constraint or row-level security policy (the real lock)
  SRV  = checked on the server before the write
  UI   = checked in the form (a courtesy only, never the only check)

NOTE A — why story is not "letters only"
--------------------------------------------------------------------
"Letters only" would reject real entries: Khmer vowel signs and the
coeng sign are combining marks, not letters, so ប្រហុក itself fails a
letters-only check. It would also reject numbers ("2-3 weeks"),
Khmer punctuation (។), and names like "Tonlé Sap". AGENTS.md rule 6
says Khmer is never stripped. So the rule is: accept all text, and
make sure it is always shown as text and never run.
{{7*7}} and <script> are then harmless, they appear on the page as
those literal characters.
